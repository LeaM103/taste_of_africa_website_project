# 🍲 Tastes of Africa

## About the Project

Tastes of Africa is a multi-page website that celebrates the rich and diverse culinary traditions of Africa. It introduces visitors to African dishes, recipes, cooking methods, food cultures, and different culinary regions.

The website was developed using HTML5, CSS3, and JavaScript to create an attractive, responsive, and interactive user experience.

## 🌍 Live Website

[Visit Tastes of Africa]()

## 🎯 Project Objectives

- Promote African food heritage and culture.
- Introduce visitors to traditional African dishes.
- Share recipes, ingredients, and cooking instructions.
- Explore culinary traditions across African regions.
- Practise HTML, CSS, JavaScript, and DOM manipulation.

## 📄 Website Pages

The website contains five main pages:

1. **Home Page:** Introduces Tastes of Africa and showcases featured African dishes and food trends.
2. **Recipes Page:** Provides recipes, ingredients, cultural descriptions, and cooking instructions.
3. **Culinary Regions Page:** Explores food traditions from West, East, and North Africa.
4. **About Us Page:** Explains the website's mission and the history and global influence of African cuisine.
5. **Contact Page:** Allows visitors to send messages through a contact form.

## ✨ Features

- Responsive website layout.
- African-inspired colours and Google Fonts.
- Interactive recipe filtering by region.
- Add-to-favorites functionality using localStorage.
- Jollof Rice ingredient serving scaler.
- Dark and light mode toggle.
- Contact form validation using JavaScript.
- Dynamic thank-you message after successful form submission.
- Food images and embedded media.
- Interactive navigation across all five pages.

## 🛠️ Technologies Used

- **HTML5:** Website structure and semantic elements.
- **CSS3:** Styling, layouts, colours, and responsiveness.
- **JavaScript:** Interactive features and DOM manipulation.
- **LocalStorage:** Saving users' favorite recipes.
- **Google Fonts:** Custom typography.
- **Git and GitHub:** Version control and project hosting.
- **GitHub Pages:** Website deployment.

## 🚀 How to Run the Project Locally

1. Clone the repository:

```bash
git clone https://github.com/LeaM103/taste_of_africa_website_project.git
```

2. Open the project folder:

```bash
cd taste_of_africa_website_project
```

3. Open `index.html` in your web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension.
